# Atlas Canon source provenance

The design authority for this work is the repository owner's **Resilience Atlas Design Canon v4.0** package, including its governing Canon, Material Specifications, Motion Specification, Component Catalog, Engineering Implementation Guide, Contributor Handbook, and Atlas Test / quality-gate materials.

This repository does not duplicate the full Resilience design-standard package. It records the Omni-specific adoption contract and pins the material/motion values needed by the current interface slice.

When the upstream Canon changes, Omni should update deliberately through a reviewed PR rather than silently drifting its token values or component semantics.
